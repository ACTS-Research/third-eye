CHECKThe screen may lock. iOS would not promise to keep it awake, which usually means Low Power Mode is on. Turn it off in Control Centre, or set Auto-Lock to Never.
YOUSilence calls. A call takes the screen and stops the camera. Turn on a Focus, or Airplane Mode with Wi-Fi back on.
YOUKeep Safari in front. Guided Access (triple-click the side button) stops a stray swipe leaving it.
The start screen stays short: the mark, the name, the room and START. The check comes after the tap, because only then can the page know what iOS allowed. If everything passes it shows for a moment and goes live by itself; it stops and waits for GO LIVE only when a line reads CHECK. The two YOU lines are things the page cannot see: they show on the first run of the day, not every time.
